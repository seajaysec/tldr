# f2

> Fast, safety-first bulk renamer for files *and* directories.  
> Runs in dry-run mode by default – add `-x/--exec` to apply changes.  
> Supports regex or literal search, variables (EXIF, ID3, hash, dates …), CSV-driven renames, conflict-fixing, undo, pairing, and more.  
> More information: <https://github.com/ayoisaiah/f2>.

- **Dry-run: change every `.svg` to `.tmp.svg` in the current directory**  
  `f2 -f '.svg' -r '.tmp.svg'`

- **Execute the same rename (commit changes with `-x`)**  
  `f2 -f '.svg' -r '.tmp.svg' -x`

- **Literal string find/replace (no regex)**  
  `f2 -f '{{old}}' -r '{{new}}' -s`

- **Strip text by omitting a replacement**  
  `f2 -f '-unsplash'`

- **Change `.jpeg` → `.jpg`, case-insensitive and ignore the extension itself**  
  `f2 -f 'jpeg' -r 'jpg' -i -e`

- **Recursive rename `.js` → `.ts`, but only one directory deep**  
  `f2 -f 'js' -r 'ts' -R -m 1`

- **Rename directories too (target *only* dirs)**  
  `f2 -f '{{old}}' -r '{{new}}' -D`

- **Apply an auto-incrementing zero-padded index**  
  `f2 -f '.*\\.' -r '{%03d}.{{ext}}'`

- **Prefix images with EXIF original date (YYYY-MM-DD)**  
  `f2 -f '.*' -r '{x.DateTimeOriginal.YYYY}-{x.DateTimeOriginal.MM}-{x.DateTimeOriginal.DD}_{{f}}{{ext}}'`

- **Rename paired RAW+JPG sets to the same stem (`Photo_001`, `Photo_002`, …)**  
  `f2 -r 'Photo_{%03d}' --pair -x`

- **Drive a rename from a CSV file (`source,new_name`)**  
  `f2 --csv {{file.csv}}`

- **Full photo-library re-org: date-based folders, pairing, conflict-safe, clean empty dirs**  
  `f2 -r '{x.cdt.YYYY}/{x.cdt.MM}-{x.cdt.MMM}/{x.cdt.YYYY}-{x.cdt.MM}-{x.cdt.DD}/{%03d}' -R --pair --reset-index-per-dir -F --fix-conflicts-pattern '%03d' --sort time_var --sort-var '{x.cdt}' -x --clean`
